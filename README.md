
# Transportation Vehicle Management System

## Project Overview

This is a modern, responsive web application for managing and monitoring a fleet of transportation vehicles. The application provides real-time insights into vehicle status, battery levels, locations, and maintenance needs.

## Features

- **Vehicle Dashboard**: Comprehensive overview of the entire vehicle fleet
- **Vehicle Status Tracking**: 
  - Real-time status indicators (Active, Maintenance, Charging, Inactive)
  - Battery level monitoring
  - Location tracking
- **Responsive Design**: Fully responsive and mobile-friendly interface
- **Modern UI**: Built with the latest web technologies

## Technologies Used

- **Frontend**: React
- **Styling**: Tailwind CSS
- **UI Components**: Shadcn/UI
- **State Management**: React Query
- **Routing**: React Router
- **Icons**: Lucide React
